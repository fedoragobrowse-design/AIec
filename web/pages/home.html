Computers for AI agents.

AgentForge hands an autonomous agent a real, isolated computer — its own kernel, filesystem and network — that it can use thousands of times an hour and throw away. Clone a repo, run code, edit files, run tests, read the diff, destroy. No SSH, no shared machines, no cleanup.

Built for coding agents, not terminals

Isolated by default

Public workloads run in Firecracker microVMs. A tenant cannot request a weaker runtime and downgrade their own isolation.

Disposable

Create, use, destroy. Sandboxes are cheap, short-lived and billed while they run, so agents can churn through them freely.

Safe to run hostile code

Per-sandbox kernel, filesystem and network namespace. Egress is filtered so a sandbox cannot reach your LAN, metadata services or other tenants.

Recoverable

Sandboxes are fenced with monotonic lease generations. If a worker dies the control plane reassigns the sandbox and reconstructs its workspace.

Real repos

Git, CA certificates, Python, curl and tar are in the image. Clone over HTTPS, edit in place, run the tests, read the diff back.

One API

REST, a Python SDK and a Rust SDK. Switching between Cloud and your own host is a base URL, not a rewrite.

A real coding workflow

This is the workflow the platform is built for, and it runs entirely through the public API with no host-side shortcuts. 

box = af.sandboxes.create(image="agentforge:latest")

box.exec(["git", "clone", "--depth", "1", REPO, "/workspace/repo"])
box.exec(["sh", "-c", "cd /workspace/repo && git status --porcelain"])
box.exec(["sh", "-c", "cd /workspace/repo && printf '\\n# change\\n' >> README"])
box.exec(["sh", "-c", "cd /workspace/repo && python -m pytest -q"])
diff = box.exec(["sh", "-c", "cd /workspace/repo && git --no-pager diff"])
print(diff["stdout"])
box.destroy()

What it is not

AgentForge is not a notebook, not a CI runner, and not a place to keep long-lived state. It is a control plane for short-lived, untrusted, agent-driven computers. If you need durable storage between runs, that is what snapshots are for.

Public alpha. Invite-only signup, limited capacity, no SLA. Current limitations are listed in full on the status and security pages.
