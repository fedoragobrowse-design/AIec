Pricing

AIec is open source. There is no hosted version, so there is nothing to charge you for and nothing to meter.

Software

Free. Apache 2.0. Clone it, run it, fork it, audit it. The repository is the product.

Compute

Yours. The hosts you run workers on, with the CPU, RAM and disk your workloads need. That is the entire cost model.

Storage

Yours. PostgreSQL and any S3-compatible object store, sized by how long you keep artifacts and workspace snapshots.

Your time

The real cost. Upgrades, patching, backups, monitoring and capacity planning are yours, which is also why the deployment path is documented rather than hidden behind a control panel.

What you still get

AIec records usage against your own tenants even though nobody bills for it: sandbox runtime seconds, vCPU seconds, GB-seconds of memory, disk, snapshot bytes, network where measurable, and commands executed. It is exposed through GET /v1/usage and exported to Prometheus, so you can see what your cluster is actually doing and what it would cost you elsewhere.

Quotas and rate limits are enforced the same way, because a self-hosted cluster still has to survive a runaway agent.

Cloud, later

A hosted AIec is something we may offer eventually. If it happens it will be optional, priced by the same usage numbers you can already export, and running it would not change a line of your code — the API, the SDK and the runtime model are the ones in this repository.

It does not exist today, and nothing here depends on it.
